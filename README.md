# 다짱

친구랑 1:1로 운동·식단·몸무게 인증 맞짱 뜨는 개인용 웹앱(PWA). 방 코드 하나로 친구를 초대하고, 주 3회 운동 인증을 못 하면 벌금. 식단은 AI가 사진을 읽어 칼로리를 계산해 줘요.

## 규칙

### 방

- 방(Room) 하나 = 1:1 맞짱. 방을 만들면 6자리 방 코드가 나오고, 친구가 그 코드로 들어와 닉네임을 정하면 둘이 매칭됨
- 친구가 여러 명이면 그만큼 방을 여러 개 만들 수 있음 (각 방은 완전히 독립적으로 인증/벌금 관리)
- 같은 사람이 여러 방에 있으면 계정을 연결해서, 한 방에서 인증하면 연결된 다른 방에도 똑같이 기록됨 (운동, 식단, 몸무게 모두)

### 운동 인증

- 주 3회 인증샷 업로드 (self-report, 타이머 없음), **하루 1장만 인정** — 같은 날 다시 올리면 이전 사진은 자동으로 교체됨
- **사진에 찍힌 날짜로 인증** — 사진 속 촬영 시각(EXIF)을 읽어서 찍은 날 칸에 기록. 이번 주에 찍은 사진만 인정되고(지난주 사진은 거절), 캡처처럼 촬영 정보가 없는 사진은 올린 날로 인정
- **하루는 오전 6시에 바뀜** (KST) — 자기 전 새벽에 운동해도 그날 인증으로 인정. 한 주는 월요일 오전 6:00 ~ 다음 주 월요일 오전 5:59. **마감 지나면 그 주에 사진 추가 불가 (소급 불가)**
- 마감 시점 기준 3회 미만이면 부족한 횟수 × 5,000원
- 사진을 누르면 **이모티콘 반응**(❤️ 🔥 👏 🤔 ❓)을 남길 수 있음. 사진마다 한 번, 취소 불가
- 인증하기로 올린 사진은 AI가 **음식 / 체중계 / 운동**을 알아서 구분해 각각 식단, 몸무게, 운동 인증으로 올림 (탭을 어디에 두었는지는 상관없음)

### 식단 인증

- 음식 사진을 올리면 AI가 음식 이름과 칼로리를 읽어 **확인 없이 바로 기록**. 잘못 읽었으면 수정 창에서 이름을 고치면 칼로리를 다시 계산하고
- 식단 제목은 음식 이름에서 자동으로 만들어짐. 사진에 보이는 양 전체를 기준으로 계산하고, 이름에 양을 적으면(예: 반 판) 그 양을 반영
- 주간 표에서 운동 | 식단으로 전환해서 볼 수 있고, 식단 달력은 하루 칼로리를 400kcal 단위 히트맵으로 보여줌. 월요일 주간 결과 팝업에는 하루 평균 칼로리가 같이 나옴
- 친구 식단 사진에도 이모티콘 반응을 남길 수 있음
- AI가 못 읽은 사진(음식·체중계·운동이 아니거나 분석 실패)은 기록하지 않고 다시 올리라고 안내
- **AI 사용 한도**: 한 사람이 하루(오전 6시 기준) 사진 분석 12회, 앱 전체로는 한 달 300 크레딧까지. 넘으면 AI 없이 안내 문구만 나옴 (환경변수로 조절 가능)

### 몸무게 인증

- 일주일에 한 번 체중계 사진으로 인증. AI가 숫자를 읽고, 사용자가 맞다고 확인하면 기록됨 (20~300kg 범위만 인정)
- **몸무게는 본인과 AI만 봄** — 친구에게는 지난 기록보다 늘었는지 줄었는지(▲▼)만 보이고 숫자는 어떤 API에도 내려가지 않음

### 벌금 (운동 외)

- **몸무게 벌금**: 그 주에 인증을 안 했거나 지난 기록보다 늘었으면 합의한 금액 1회 (0 ~ 30,000원, 5,000원 단위)
- **식단 벌금**: 식단을 하나도 안 올린 날마다 합의한 금액 (0 ~ 5,000원, 1,000원 단위). 이미 끝난 날만 셈
- 둘 다 **방의 두 사람이 합의해야** 정해짐 — 한쪽이 금액을 제안하고 상대가 수락하면 **다음 주부터** 적용(소급 없음). 벌금을 끄려면 상대에게 중단을 제안하고, 수락하면 다음 주부터 중단
- 벌금이 꺼져 있으면 해당 인증 알림과 배너도 나오지 않음

### 봐주기 · 쉬기

- **사정 봐달라하기**: **한 달에 한 번만** 쓸 수 있음(대기 중이거나 허락된 요청만 횟수로 침 — 거절당하면 다시 요청 가능, 매달 1일 오전 6시에 초기화). 사유 적어서 요청 → 상대방이 허락하면 **그 주 벌금이 전액 면제**. 상대방은 허락/거절하면서 짧은 답장을 남길 수 있고(선택), 결과와 답장은 다음에 앱 열 때 팝업으로 알려줌
- **쉬어가기**: 요청 → 상대가 수락하면 둘 다 쉼 (여행 등으로 몇 주). 수락하지 않고 거절("나라도 지킨다")하면 **요청한 사람만** 그 기간 벌금이 면제되고, 혼자 쉬는 중에는 **쉬기 취소**로 이번 주부터 다시 도전할 수 있음(친구가 앱을 열면 팝업으로 알려줌)
- **리본**: 친구가 쉬는 주에 나는 쉬지 않고 목표(3회)를 채우면 리본 1개. 이후 벌금이 생긴 주에 월요일 정산이 **가장 오래된 리본부터 자동으로 써서** 그 주 벌금을 면제
- **방 삭제**: 한쪽이 요청하면 상대방이 수락해야 실제로 삭제됨
- 쉬는 방, 혼자 쉬는 사람, 사정을 봐준 주에는 리마인드 알림도 가지 않음

### 사진 보관

- 인증샷은 업로드 전 브라우저에서 자동으로 리사이즈/압축됨
- **주가 끝나면 그 주의 운동·식단 사진은 자동 삭제** (매일 정오 정리). 인증 횟수, 식단 이름·칼로리 기록은 그대로 유지됨

## 기능

| | |
|---|---|
| 방 코드로 시작 | 링크 없이 6자리 코드만 알아도 참여 가능 |
| 대결 카드 | 이번 주 인증 횟수를 캐릭터 배틀 형태로 보여줌 (많이 한 쪽이 커짐). 상대 캐릭터를 눌러 **콕 찌르기**, 말풍선 멘트는 직접 설정 |
| 운동 / 식단 / 몸무게 인증 | 사진 한 장으로 인증하면 AI가 종류를 알아서 분류 |
| 식단 칼로리 분석 | AI가 음식 이름과 칼로리 추정, 달력 히트맵, 수정 창 |
| 사진 반응 | 운동·식단 사진마다 이모티콘 하나 남기기 |
| 아이폰 동작 버튼 연동 | 단축어로 사진 찍고 바로 올리기 ([설정 방법](docs/meal-shortcut.md)) |
| 사정 봐달라하기 | 요청 → 허락/거절(+답장) → 결과 팝업까지 완결된 흐름 |
| 쉬어가기 / 리본 | 상호 동의 쉬기, 혼자 쉬기, 친구가 쉴 때 채우면 리본 |
| 벌금 약속 | 몸무게·식단 벌금을 친구와 합의해서 설정 |
| 모임 통장 | 벌금 보낼 공용 계좌 하나만 등록해두면 홈 화면에서 바로 계좌번호 복사 / 은행 앱 열기 |
| 통산전적 · 지난 기록 | 트로피 창에서 누적 인증 횟수, 승리한 주, 누적 벌금을 보고, 주차별 결과 확인 후 정산완료 체크 |
| 웹 푸시 알림 | 아래 표 참고 |
| 새 소식 팝업 | 업데이트가 있으면 앱을 처음 여는 한 번만 마스코트가 알려줌 |
| 외부 연동 API | 다른 앱(mypt)이 운동 인증일을 읽는 읽기 전용 API (토큰 필요) |

### 알림 (KST)

| 시각 | 내용 |
|---|---|
| 매일 오후 6시 | 오늘 식단 인증을 아직 안 했고 식단 벌금이 켜져 있으면 알림 |
| 매일 저녁 7시 | 남은 날 안에 채우려면 매일 해야 하는 시점부터 운동 인증 리마인드 |
| 월요일 오전 9시 | 지난 주 결과 확정, 리본 획득 알림 |
| 그때그때 | 사정 봐달라하기·쉬어가기 요청과 결과, 콕 찌르기, 인증 결과 (알림을 누르면 열린 창으로 이동) |

알림은 홈 화면에 추가한 앱에서 알림을 켠 기기로 와요.

## 기술 스택

- [Next.js 16](https://nextjs.org) (App Router, Turbopack), React 19, TypeScript
- [Prisma](https://www.prisma.io) + PostgreSQL ([Neon](https://neon.com))
- Tailwind CSS v4
- [sharp](https://sharp.pixelplumbing.com), [exifr](https://github.com/MikeKovarik/exifr) (사진 리사이즈, 촬영 시각 읽기)
- 식단·체중계 사진 분석은 AI API 게이트웨이(기본 모델 `gpt-6-luna`) 사용
- [web-push](https://github.com/web-push-libs/web-push) (VAPID 기반 웹 푸시)
- PWA (manifest + service worker), Vercel Cron (알림, 주간 정산, 사진 정리)

## 로컬 개발

1. 의존성 설치
   ```bash
   npm install
   ```
2. `.env` 채우기

   | 변수 | 설명 |
   |---|---|
   | `DATABASE_URL` | Postgres 연결 문자열 ([neon.com](https://neon.com)에서 무료로 만들 수 있음) |
   | `SESSION_SECRET` | 로그인 세션 서명용. 아무 랜덤 문자열 |
   | `CRON_SECRET` | 크론 엔드포인트 보호용. 아무 랜덤 문자열 |
   | `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | 웹푸시 키 (아래 참고). `NEXT_PUBLIC_`은 public key와 같은 값 |
   | `BAZE_API_KEY` | 식단·체중계 사진 분석 AI 키. 없으면 AI 분석이 실패로 처리됨 |
   | `BAZE_BASE_URL`, `BAZE_IMAGE_MODEL` | (선택) AI 게이트웨이 주소, 모델 이름 |
   | `AI_PHOTO_LIMIT`, `AI_MONTHLY_CREDITS` | (선택) 하루 사진 분석 횟수(기본 12), 한 달 앱 전체 크레딧(기본 300) |
   | `OWNER_CODE` | 내 방 목록(관리자) 화면 코드. **운영에서는 꼭 길고 추측하기 어려운 값으로 설정** (없으면 기본 코드로 열리므로 위험) |
   | `EXTERNAL_TOKEN` | (선택) 외부 앱용 읽기 전용 API 토큰 |

   웹푸시 키 생성:
   ```bash
   npx web-push generate-vapid-keys
   ```
3. DB 마이그레이션 적용
   ```bash
   npx prisma migrate dev
   ```
4. 로컬 실행
   ```bash
   npm run dev
   ```
5. `http://localhost:3000` 접속 → "방 만들기" → 닉네임 정하기 → 나오는 방 코드를 친구에게 전달

배포는 Vercel + Neon을 기준으로 해요. `npm run build`가 `prisma migrate deploy`까지 실행하고, 크론은 `vercel.json`에 있어요.

## 사용법

1. 앱 접속 → "방 만들기" → 나온 방 코드 확인
2. "초대 공유하기"로 친구에게 코드 전달 (카톡 등), 혹은 친구가 홈 화면에서 코드를 직접 입력
3. 친구가 코드로 입장 → 닉네임 정하고 참여
4. 각자 알림 종 아이콘으로 푸시 허용 (홈 화면에 앱 추가 권장)
5. 운동·식단·체중계 사진은 우측 하단 "인증하기"로 올리면 AI가 알아서 분류. 아이폰이면 설정 → 실험실에서 동작 버튼을 연동하면 더 간단
6. 몸무게·식단 벌금을 쓰려면 설정 → 실험실에서 친구와 금액을 합의
7. 트로피 창의 "지난 기록"에서 주차별 결과 확인, 벌금 낸 사람은 본인이 직접 "정산완료" 체크
8. 여러 친구랑 하고 싶으면 내 정보에서 로그아웃 후 새 방을 또 만들면 됨
