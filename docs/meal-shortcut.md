# 아이폰 액션 버튼으로 식단 올리기

앱 **내 정보 → 실험실 → 식단 인증 → 아이폰 액션 버튼 → 연동**에 같은 내용이 5장짜리 도움말로 들어 있어요.

## 만드는 순서

1. **내 주소 만들기** (앱 연동 도움말 1장)
2. **단축어** 앱 → **＋** → 이름 `식단`
3. 동작 추가: **사진 찍기**
4. 동작 추가: **이미지 크기 변경** → 너비 `1024`
5. 동작 추가: **이미지 변환** → 형식 `JPEG`
6. 동작 추가: **URL 콘텐츠 가져오기**
   - URL: 앱에서 복사한 주소 (`https://배포주소/api/external/meal?t=내코드`)
   - 방법: `POST`
   - 요청 본문: **파일** → **변환된 이미지**
7. 동작 추가: **결과 보기** → **완료**
8. **설정 → 액션 버튼 → 단축어 → 식단** (버튼이 없는 폰: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 두 번 탭 → 식단)

## 서버 규칙 (`POST /api/external/meal`)

- 누구의 사진인지: 주소 끝 `?t=코드` 또는 `Authorization: Bearer 코드`
- 사진: 요청 본문 전체가 파일 / `multipart/form-data`의 첫 파일 / JSON `{"imageBase64", "mimeType"}`
- 응답: 파일로 보내면 글자(`text/plain`), JSON으로 보내면 `{"ok", "message"}`
- 사진 종류는 파일 앞부분으로 직접 판단. 3MB 초과(Vercel은 요청 4.5MB 제한)와 HEIC는 거절하고 고칠 곳을 알려 줌
- 하루 사진 분석 12회, 이번 달 앱 전체 300 크레딧을 넘으면 AI 없이 안내 문구만 돌려줌

## 결과 보기에 이런 글이 뜨면

| 글 | 고칠 곳 |
|---|---|
| 연결 코드가 올바르지 않아요 | 앱에서 주소를 다시 복사해 URL에 붙여넣기 |
| 실험실에서 식단 인증을 먼저 켜 주세요 | 앱 내 정보에서 식단 인증 켜기 |
| 사진이 HEIC 형식이에요 | 이미지 변환(JPEG) 동작 확인 |
| 사진이 너무 커요 | 이미지 크기 변경 너비 1024 확인 |
| 사진이 안 왔어요 | 요청 본문이 파일 → 변환된 이미지인지 확인 |
| AI 분석을 다 썼어요 | 오늘/이번 달 한도. 앱에서 직접 적어 올리기 |

알림이 안 오면 앱을 홈 화면에 추가하고 알림을 켠 폰인지 확인하세요. 알림이 없어도 앱을 열면 확인 대기 배너가 보여요.
