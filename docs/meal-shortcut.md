# 아이폰 동작 버튼으로 식단 올리기

앱 **내 정보 → 실험실 → 식단 인증 → 아이폰 동작 버튼 → 연동**에 같은 내용이 5장짜리 도움말로 들어 있어요.

## 만드는 순서

1. **내 주소 만들기** (앱 연동 도움말 1장)
2. **단축어** 앱 → **＋** → 이름 `식단`
3. 동작 추가: **사진 찍기**
4. 동작 추가: **이미지 크기 변경** → 너비 `1024`
5. 동작 추가: **이미지 변환** → 형식 `JPEG`
6. 동작 추가: **URL 콘텐츠 가져오기**
   - URL: 앱에서 복사한 주소 (`https://배포주소/api/external/meal?t=내코드`)
   - 메소드: `POST`
   - 요청 본문: **파일** → **변환된 이미지**
7. 오른쪽 위 **완료**로 저장
8. **설정 → 동작 버튼 → 단축어 → 식단** (버튼이 없는 폰: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 두 번 탭 → 식단)

## 서버 규칙 (`POST /api/external/meal`)

- 누구의 사진인지: 주소 끝 `?t=코드` 또는 `Authorization: Bearer 코드`
- 사진: 요청 본문 전체가 파일 / `multipart/form-data`의 첫 파일 / JSON `{"imageBase64", "mimeType"}`
- 응답: 파일로 보내면 글자(`text/plain`), JSON으로 보내면 `{"ok", "message"}`
- 사진 종류는 파일 앞부분으로 직접 판단. 3MB 초과(Vercel은 요청 4.5MB 제한)와 HEIC는 거절하고 고칠 곳을 알려 줌
- 하루 사진 분석 12회, 이번 달 앱 전체 300 크레딧을 넘으면 AI 없이 안내 문구만 돌려줌

## 결과는 알림으로 와요

AI가 사진을 읽으면 확인 없이 바로 기록되고 "식단에 올라갔어요" 알림이 와요. 잘못 읽었으면 앱에서 고치거나 지우면 돼요. 사진은 AI가 음식이면 식단, 체중계면 몸무게, 운동이면 운동 인증으로 알아서 나눠서 올려요. 안 올라간 이유(사진이 HEIC예요, 사진이 너무 커요, 사진을 인식하지 못했어요, 이번 주에 찍은 사진이 아니에요, 오늘/이번 달 AI 분석 한도 등)도 "식단을 못 올렸어요" 알림으로 와요. 연결 코드가 틀린 경우만 알림을 보낼 대상을 알 수 없어서 아무 알림이 없어요. 그땐 앱에서 주소를 다시 복사해 URL에 붙여넣어요.

## 예외 상황

| 상황 | 앱에서 올릴 때 | 단축어로 올릴 때 |
|---|---|---|
| 운동 사진 | "운동 사진으로 읽어서 운동 인증으로 올렸어요" 안내 후 운동 인증으로 올라감 | 운동 인증으로 올라가고 "운동 인증" 알림 |
| 음식/체중계/운동 어디에도 안 맞음 | "사진을 인식하지 못했어요. 다시 올려 주세요" 안내, 기록 안 함 | 기록 없이 "사진을 인식하지 못했어요" 알림. 다시 올리기 |
| AI 분석 실패 (키 없음, 오류) | 칼로리 없이 "식사"로 바로 기록됨 (식단 창의 수정에서 고침) | 같음 |
| 오늘/이번 달 AI 분석 한도 초과 | 칼로리 없이 "식사"로 바로 기록됨 | 기록 없이 "못 올렸어요" 알림. 나중에 다시 올리기 |
| 음식 이름 오타 | 수정창에서 음식 아래에 계산된 칼로리가 보임. 이상하면 이름을 고침 | 같음 (기록 뒤 식단 창의 수정에서) |
| 칼로리 계산 실패 (한도 초과 등) | 음식 아래에 빨간 안내가 뜨고 0 kcal로 저장됨 | 같음 |

AI는 음식 이름과 "1인분 기준" 칼로리만 추정해요. 먹은 양은 수정창에서 음식마다 1/4, 절반, 3/4, 다 먹음으로 직접 골라요.

알림은 앱을 홈 화면에 추가하고 알림을 켠 폰에서만 와요. 알림이 없어도 앱을 열면 확인 대기 배너가 보여요.
