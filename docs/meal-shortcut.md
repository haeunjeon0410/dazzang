# 아이폰 액션 버튼으로 식단 올리기

맥이나 애플 개발자 계정 없이, 아이폰에 기본으로 있는 **단축어 앱**만으로 만든다.

## 흐름

액션 버튼 → 단축어 실행 → 카메라 → 사진 찍기 → 서버(`POST /api/external/meal`) → AI가 음식을 읽어 **확인 대기** 초안으로 저장 → 푸시 알림 → 앱에서 확인(필요하면 고치기) → 친구와 공유

## 서버 주소

| 항목 | 값 |
|---|---|
| 주소 | `https://배포주소/api/external/meal` |
| 방법 | `POST` |
| 헤더 | `Authorization: Bearer 개인토큰`, `Content-Type: application/json` |
| 본문 | `{"imageBase64": "...", "mimeType": "image/jpeg"}` |
| 응답 | `{"ok": true, "message": "제육덮밥 약 780 kcal로 읽었어요. 앱에서 확인해 주세요"}` |

개인 토큰은 앱의 내 정보 → 실험실 → 식단 인증을 켠 뒤 "연결 코드 만들기"로 만든다. 다시 만들면 이전 토큰은 바로 못 쓴다.

## 단축어 만들기

1. 새 단축어 이름 "식단"
2. 사진 찍기
3. 이미지 크기 변경: 긴 변 `1024`
4. 이미지 변환: JPEG
5. Base64로 인코딩: 줄바꿈 `없음`
6. URL 콘텐츠 가져오기: 위 표대로 (본문 JSON의 `imageBase64`는 5번 결과, `mimeType`은 텍스트 `image/jpeg`)
7. 사전에서 값 가져오기: 키 `message` → 결과 보기
8. 설정 → 액션 버튼 → 단축어 → "식단"

## 한계

- 액션 버튼은 아이폰 15 Pro 이후(16 시리즈 포함)에만 있다. 그 전 폰은 뒷면 탭이나 잠금화면 버튼에 같은 단축어를 연결한다.
- "사진 찍기"는 카메라 화면이 뜨고 셔터를 누른 뒤 "사진 사용"을 눌러야 이어진다 (iOS가 막아서 완전 자동 촬영은 안 된다).
- 단축어는 아이폰에서 직접 만들어 봐야 한다. 동작 이름이 iOS 버전에 따라 조금 다를 수 있다.
- 푸시 알림은 앱을 홈 화면에 추가하고 알림을 켠 폰에서만 온다.
