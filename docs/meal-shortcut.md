# 아이폰 액션 버튼으로 식단 올리기 (처음 해 보는 사람용)

액션 버튼을 한 번 누르고 사진만 찍으면 식단이 앱에 올라가게 만드는 방법이에요.
맥이나 개발자 계정은 필요 없고, 아이폰에 기본으로 들어 있는 **단축어** 앱만 쓰면 돼요.
순서대로 한 단계씩만 따라 하세요. 총 11단계, 10분쯤 걸려요.

> 시작 전에: 앱에서 **내 정보 → 실험실 → 식단 인증**을 켜 두세요. 앱 안의 **연동** 버튼을 누르면 이 내용이 한 장씩 넘겨 보이는 도움말로도 나와요.

---

## 1단계. 연결 코드 만들기
앱 **내 정보 → 아이폰 액션 버튼 → 연동**을 누르고 **연결 코드 만들기**를 눌러요.
"✓ 코드가 만들어졌어요"가 보이면 끝이에요. 이 코드는 "이 사진은 내 거예요"라고 알려 주는 열쇠라서 남에게 알려 주면 안 돼요.

## 2단계. 새 단축어 만들기
1. 아이폰에서 **단축어** 앱을 열어요. (파랑·보라색 네모가 겹친 아이콘이에요)
2. 오른쪽 위 **＋** 를 눌러요.
3. 맨 위 이름 칸을 눌러 이름을 **식단** 으로 바꿔요.

## 3단계. ① 사진 찍기 넣기
1. 아래쪽 **동작 검색** 칸을 눌러요.
2. **사진 찍기** 라고 입력해요.
3. 나온 결과 중 "사진 찍기"를 눌러요. 화면 위쪽에 칸이 하나 생겨요.

## 4단계. ② 사진 가볍게 줄이기
1. 다시 검색 칸에 **이미지 크기 변경** 을 입력하고 눌러요.
2. 생긴 칸에서 **너비** 를 눌러 **1024** 로 바꿔요. 높이는 그대로 두세요.

## 5단계. ③ JPEG로 바꾸기
1. 검색 칸에 **이미지 변환** 을 입력하고 눌러요.
2. 칸 안의 형식 글씨를 눌러 **JPEG** 를 골라요.

## 6단계. ④ 사진을 글자로 바꾸기
1. 검색 칸에 **Base64로 인코딩** 을 입력하고 눌러요.
2. 칸 안의 **줄바꿈** 글씨를 눌러 **없음** 을 골라요. (안 보이면 칸 오른쪽의 **⌄** 를 눌러요)

## 7단계. ⑤ 서버로 보내기 (1/2) 주소
1. 검색 칸에 **URL 콘텐츠 가져오기** 를 입력하고 눌러요.
2. 칸의 **URL** 자리에 앱 연동 도움말의 **주소 복사하기** 로 복사한 주소를 붙여 넣어요.
3. 칸 오른쪽의 **⌄** (화살표)를 눌러 펼친 뒤, 방법을 **POST** 로 바꿔요.

## 8단계. ⑤ 서버로 보내기 (2/2) 내용
1. 펼친 칸에서 **헤더 추가** 를 두 번 눌러요.
   - 첫째: 키 `Authorization`, 값은 앱에서 **연결 코드 복사하기** 로 복사한 것을 붙여 넣어요.
   - 둘째: 키 `Content-Type`, 값 `application/json`
2. **요청 본문** 을 **JSON** 으로 두고 **새 필드 추가 → 텍스트** 를 두 번 눌러요.
   - 첫째: 키 `imageBase64`, 값은 글자 대신 6단계 결과(**Base64 인코딩됨**)를 골라요.
   - 둘째: 키 `mimeType`, 값 `image/jpeg`

## 9단계. ⑥ 결과 알림 띄우기
1. 검색 칸에 **사전에서 값 가져오기** 를 입력하고 눌러요. 키 자리에 `message` 를 적어요.
2. 검색 칸에 **결과 보기** 를 입력하고 눌러요.
3. 오른쪽 위 **완료** 를 눌러 저장해요.

## 10단계. 액션 버튼에 연결하기
**액션 버튼이 있는 폰 (아이폰 15 Pro 이후)**
1. **설정 → 액션 버튼** 으로 들어가요.
2. 화면을 옆으로 넘겨 **단축어** 를 고르고, **식단** 을 선택해요.

**액션 버튼이 없는 폰**
**설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 두 번 탭 → 식단** 을 골라요.

## 11단계. 해 보기
1. 액션 버튼(또는 뒷면 두 번 탭)을 눌러요.
2. 카메라가 뜨면 음식을 찍고 **사진 사용** 을 눌러요.
3. 잠시 뒤 "식단 확인" 알림이 오면 성공이에요. 앱 식단 화면에서 **아이폰으로 올린 식단 N건 확인하기** 를 눌러 확인하고 저장하면 친구에게도 보여요.

---

## 잘 안 될 때
- **"토큰이 올바르지 않아요"가 떠요** → 8단계의 `Authorization` 값이 `Bearer 연결코드` 전체인지 확인해요. 앱에서 코드를 다시 만들었다면 새 코드로 바꿔야 해요.
- **"실험실에서 식단 인증을 먼저 켜 주세요"가 떠요** → 앱 내 정보에서 식단 인증을 켜요.
- **"AI 분석을 다 썼어요"가 떠요** → 오늘(또는 이번 달) AI 사용 한도에 걸린 거예요. 앱에서 직접 적어서 올릴 수 있어요.
- **알림이 안 와요** → 앱을 홈 화면에 추가하고 알림을 켠 폰에서만 알림이 와요. 알림이 없어도 앱을 열면 확인 대기 배너가 보여요.
- **카메라가 바로 안 켜지고 "사진 사용"을 눌러야 해요** → iOS 규칙이라 셔터를 누른 뒤 **사진 사용** 을 눌러야 이어져요.
- 단축어 동작 이름이 조금 다르게 보이면 검색 칸에 비슷한 이름을 입력해서 찾아요. iOS 버전에 따라 글씨가 조금 다를 수 있어요.
