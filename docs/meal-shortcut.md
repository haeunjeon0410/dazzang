# 아이폰 액션 버튼으로 식단 올리기

액션 버튼을 한 번 누르고 사진만 찍으면 식단이 앱에 올라가게 만드는 방법이에요.
맥이나 개발자 계정은 필요 없고, 아이폰에 기본으로 들어 있는 **단축어** 앱만 쓰면 돼요.
앱의 **내 정보 → 실험실 → 아이폰 액션 버튼 → 연동**에 같은 내용이 17장짜리 도움말로 들어 있어요.

## 흐름

액션 버튼 → 단축어 실행 → 사진 찍기 → 크기 줄이기 → JPEG로 바꾸기 → 앱 주소로 보내기 → 결과 문구 표시

앱 쪽에서는 사진을 AI가 읽어 **확인 대기** 식단으로 저장하고, 푸시 알림을 보내요. 본인이 앱에서 확인(필요하면 고치기)해야 친구에게 보여요.

## 단축어에 들어가는 동작 (순서대로)

1. **사진 찍기**
2. **이미지 크기 변경**: 너비 `1024` (Vercel이 요청 하나를 4.5MB까지만 받아서 꼭 필요해요)
3. **이미지 변환**: 형식 `JPEG` (아이폰 사진은 HEIC라서 서버와 AI가 못 읽어요)
4. **URL 콘텐츠 가져오기**
   - URL: 앱 연동 도움말의 **주소 복사하기**로 복사한 주소 (`https://배포주소/api/external/meal?t=내코드`)
   - 방법: `POST`
   - 요청 본문: **파일** → 변수 **변환된 이미지**
5. **결과 보기**
6. 설정 → 액션 버튼 → 단축어 → "식단"

## 서버 쪽 규칙 (`POST /api/external/meal`)

- **누구의 사진인지**: 주소 끝 `?t=코드` 또는 `Authorization: Bearer 코드` 헤더. 코드는 앱 연동 도움말 1단계에서 만들어요(다시 만들면 이전 주소는 못 써요).
- **사진 받는 방법** (아무거나 돼요)
  - 요청 본문 전체가 사진 파일 (`Content-Type: image/jpeg` 등, 단축어 방식)
  - 양식(`multipart/form-data`)의 첫 파일
  - JSON `{"imageBase64": "...", "mimeType": "image/jpeg"}` (예전 방식)
- **응답**: 파일로 보내면 결과 문구가 글자(`text/plain`)로 와서 "결과 보기"에 바로 떠요. JSON으로 보내면 `{"ok": true, "message": "..."}`.
- 사진 종류는 파일 앞부분을 직접 보고 판단해요. 3MB를 넘으면 "사진이 너무 커요", HEIC면 "이미지 변환(JPEG) 단계를 확인해 주세요"라고 알려 줘요.
- 하루 사진 분석 12회, 이번 달 앱 전체 300 크레딧을 넘으면 AI를 부르지 않고 안내 문구를 돌려줘요.

## 잘 안 될 때 (결과 보기에 이런 글이 떠요)

- **"연결 코드가 올바르지 않아요"** → 앱에서 주소를 다시 복사해 단축어의 URL에 붙여 넣어요. 앱에서 주소를 다시 만들었다면 새 주소로 바꿔야 해요.
- **"앱의 실험실에서 식단 인증을 먼저 켜 주세요"** → 앱 내 정보에서 식단 인증을 켜요.
- **"사진이 HEIC 형식이에요"** → 이미지 변환(JPEG) 동작이 사진 찍기 뒤에 있는지, 보내는 사진이 그 결과인지 확인해요.
- **"사진이 너무 커요"** → 이미지 크기 변경 동작이 있는지, 너비가 1024인지 확인해요.
- **"사진이 안 왔어요"** → 요청 본문이 **파일**이고, 그 파일이 변환된 이미지인지 확인해요.
- **"AI 분석을 다 썼어요"** → 오늘(또는 이번 달) 한도예요. 앱에서 직접 적어서 올릴 수 있어요.
- **알림이 안 와요** → 앱을 홈 화면에 추가하고 알림을 켠 폰에서만 와요. 알림이 없어도 앱을 열면 확인 대기 배너가 보여요.
- 카메라가 켜진 뒤 **사진 사용**을 눌러야 이어져요. iOS 규칙이라 막을 수 없어요.
- 동작 이름이 조금 다르게 보이면 검색 칸에 비슷한 이름을 입력해 찾아요. iOS 버전에 따라 글씨가 조금 다를 수 있어요.
